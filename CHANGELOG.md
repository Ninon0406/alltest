# Changelog

## Publication configuration — 2026-10-28

Added GitHub Actions to test, build and deploy the production bundle from main to GitHub Pages. Public publication was authorized by the user; successful deployment must be verified separately from pushing code.

## 0.2.0 — 2026-10-28

Milestone 2: dedicated one-shot weighted rebirth, 120 Thai names, four races and rarities, randomized parents, household histories, homelands, independent attributes and resource-affecting talents. Added an illustrated permanent Birth Record, saved hidden potential/abilities/lifespan, and schema-2 saves with unversioned/version-1 compatibility. Existing lives are never rerolled. Corrupt-save replacement requires confirmation; storage failures block unsaved births. Added a peaceful crisis retreat for weaker births, deterministic distribution/content tests, full available-branch traversal over 100 seeds, and desktop/mobile rebirth tests. No public deployment.

Milestone 2 validation: 11 unit tests and 10 desktop/mobile production-browser tests passed; production build and content-count script passed. Static hosting beneath `/alltest/` verified modules, styles, illustration, rebirth, choice effects and save reload. No public deployment was performed.

## 0.1.0 — 2026-10-28

Milestone 1: extracted original HTML/CSS/script into Vite ES modules while preserving the story and action effects. Added Thai character/guide navigation, keyboard-accessible choice buttons, mobile shell styling, original pixel landscape artwork and Escape-to-close dialogs. Introduced version-1 saves with legacy read support, validation and non-destructive corrupt-save recovery. Added seeded random utility for future rebirth work, content-count script, Vitest unit tests and desktop/mobile Playwright production tests. Added project documentation and relative build paths for future Pages deployment. No public deployment performed.
