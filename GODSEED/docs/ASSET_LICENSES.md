# Asset provenance

All PNG world/actor assets in public/assets generated locally from original drawing instructions in scripts/generate-art.mjs, scripts/generate-stage-art.mjs and scripts/generate-actor-art.mjs for this project. No borrowed game sprites, screenshots, music or CC packs. No external font download; uses available system Thai fonts. No audio files yet.

Phaser 4.2.1 MIT; Vite MIT; Zod MIT. Runtime package license text remains in dependency distributions. Generated assets are project-owned source outputs; final art quality is not implied by provenance.

0.3.0 adds16 original procedural PNGs under public/assets/art-v2:12 stage layers, props, ambient, player and training. Their editable generators and manifests are included. Existing11 PNGs retained unchanged; training is no longer a recolored/reused Pip. System fonts only, no imported third-party images or audio.
