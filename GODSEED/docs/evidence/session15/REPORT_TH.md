# GODSEED DEVELOPMENT REPORT — 0.7.0 / รอบ 15

วันที่ 2026-11-05 UTC · [เล่นเกม](https://ninon0406.github.io/alltest/)

## 1. สถานะล่าสุด

พัฒนาต่อจาก main `2126f88` รุ่น 0.6.2 โดยรักษาเกมเดิม เลือกข้อกำหนด Manual File Save เป็นงานเร่งด่วน แล้วพัฒนาเหตุการณ์ฟังเพลงของมาเรนต่อ โปรเจกต์ยังเป็นเกมส่วนแรกที่เล่นได้ มีงานโครงสร้าง ภาพ และเนื้อเรื่องค้างก่อนเวอร์ชัน 1.0

## 2. สิ่งที่พัฒนาเสร็จแล้ว

- เปลี่ยนระบบเซฟเป็น RAM และไฟล์ที่ผู้เล่นส่งออกเอง ถอด backend IndexedDB, autosave, recovery และ dependency `fake-indexeddb` จากแอปปัจจุบัน
- เพิ่มไฟล์เซฟรุ่น 2 พร้อมข้อมูล checkpoint, checksum และการตรวจความเข้ากันได้ รองรับไฟล์รุ่นเดิมเมื่อผู้เล่นเลือกเอง
- เพิ่มหน้าสรุปก่อนโหลด ปุ่มที่ปิดระหว่างเหตุการณ์ และคำเตือนก่อนทิ้งความคืบหน้าที่ยังไม่ได้ส่งออก
- สร้าง Sprite มาเรนต้นฉบับ 8 เฟรม และจัดฉากให้ผู้เล่นเดินไปนั่งฟังตามตัวเลือกจริง
- เพิ่มการตรวจ source และ browser เพื่อป้องกันการบันทึกถาวรหรือส่งเซฟไปเซิร์ฟเวอร์ ปรับการทดสอบเดิมให้ใช้ไฟล์จริงโดยรักษา assertion ด้านเกม

ไฟล์สำคัญ: [manual-session.ts](../../../src/engine/manual-session.ts), [save-file.ts](../../../src/engine/save-file.ts), [save-controls.ts](../../../src/ui/save-controls.ts), [world.ts](../../../src/scenes/world.ts), [storage.spec.ts](../../../tests/storage.spec.ts), [validate-manual-save.mjs](../../../scripts/validate-manual-save.mjs)

## 3. ระบบเซฟ

กด **บันทึกเกมเป็นไฟล์** เพื่อเริ่มดาวน์โหลด `GODSEED_Save_YYYY-MM-DD.godseed` ซึ่งมี JSON ภายใน เกมแสดงคำแนะนำ Files/Downloads และให้ผู้เล่นยืนยันหลังตรวจไฟล์เอง การเริ่มดาวน์โหลดไม่ใช่หลักฐานว่าระบบปฏิบัติการเก็บไฟล์แล้ว เมื่อเล่นต่อและข้อมูลเปลี่ยน ต้องส่งออกไฟล์ใหม่

เล่นต่อด้วย **โหลดเกมจากไฟล์ → ตรวจสรุป → ยืนยัน** ระบบตรวจขนาด นามสกุล เวอร์ชัน checksum และข้อมูลอ้างอิง Scene, Item, Spell, NPC, Choice และ Encounter ไฟล์ผิดรูปแบบหรือการยกเลิกไม่แทนสถานะที่กำลังเล่นอยู่ ไฟล์รุ่นเก่าย้ายข้อมูลใน RAM ได้เมื่อเลือกเอง

รีเฟรชกลับหน้าเริ่มเสมอ ไม่มีการกู้ความคืบหน้าจากเบราว์เซอร์ แอปไม่อ่านหรือลบฐานข้อมูลเก่า ไม่เขียน progress ลง browser storage และไม่ส่งไฟล์เซฟไปเซิร์ฟเวอร์ ก่อนเริ่มใหม่หรือออกเมนูมีตัวเลือกบันทึก เล่นต่อ และออกโดยไม่บันทึก ส่วนการปิดแท็บใช้คำเตือนมาตรฐานเมื่อเบราว์เซอร์รองรับ

ไฟล์เก็บ State ที่มีจริงครบ รวมตัวละคร HP/MP/XP, Inventory, สูตรและช่องเวท, เวลา, RNG, choices, flags, trust, ความทรงจำ และ battle turn ปัจจุบัน ระบบ Level/อุปกรณ์/mastery ที่ยังไม่ได้พัฒนาไม่ได้ถูกเติมค่าปลอม จุดโหลดใช้ checkpoint ที่เสถียรและจัดฉากตามสถานะ ไม่ได้บันทึกพิกัดระหว่างแอนิเมชัน ดู [ข้อกำหนดไฟล์เซฟ](../../SAVE_FILE_FORMAT.md)

## 4. งานภาพและแอนิเมชัน

มาเรนมี Sprite 8 เฟรมขนาดเฟรมละ 32×48 พิกเซล ผมมวยสีเงิน ผ้าคลุมพีช กระโปรงพลัม พร้อมท่ายืนและฮัมเพลง ในเหตุการณ์ CH0602 ตัวละครเดินอ้อมแปลงสมุนไพรไปนั่งม้านั่ง หันเข้าหามาเรน และคงท่านั่งระหว่างเหตุการณ์ จัดตำแหน่ง NPC และความลึกใหม่เพื่อไม่ให้ซ้อนม้านั่ง รองรับข้ามแอนิเมชันและ Reduced Motion

ภาพยังเป็นต้นแบบ ไม่รับรองคุณภาพ HD ขั้นสุดท้ายหรือฉากสวนตาม Reference 05 ทั้งฉาก รอบนี้ไม่ได้เพิ่มเสียงร้อง
