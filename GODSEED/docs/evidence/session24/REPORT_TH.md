# GODSEED EVOLUTION REPORT — รอบ 24 / 0.14.0

## 1. สิ่งที่ตรวจพบก่อนเริ่ม

ต่อจาก main `0dc39c0` และเกมเผยแพร่ 0.13.0 ที่มี 99 จุดเนื้อเรื่อง / 273 ตัวเลือก / 234 สูตรเวท / 2 หลักสูตรเส้นทางชีวิต การตรวจรอบนี้ยืนยัน Main CI ของ 0.13 ผ่านครบ 158 กรณีและ Deploy สำเร็จแล้ว จึงไม่ถือสถานะรอในรายงานเก่าเป็นปัญหาที่ยังเกิดอยู่

จุดที่ยังขาดคือภารกิจผลไม้ของพิพตาม canon, ข้อมูลบทที่เคยผูกกับบทแรก และช่วงเล่นต่อหลังบทสรุปหมู่บ้าน ระบบเซฟเดิมเป็น Manual File Save อยู่แล้ว จึงพัฒนาความเข้ากันได้และข้อมูลบทต่อจากระบบนั้น

## 2. สิ่งที่พัฒนาแล้ว

- เพิ่มภารกิจพิพ 3 จุดและการเดินทางป่าช่วงเปิด ARC 2 อีก 25 จุด รวม 28 จุดใหม่ / 67 ตัวเลือกใหม่ มีการเตรียมตัว ทดลอง แก้ปัญหา เลือกผลต่อโลก และกลับรายงานผล
- เพิ่มข้อมูลบทและเจ้าของ Content Batch ใช้ร่วมกันใน UI, validator และไฟล์เซฟ แยกบทของการเดินทางออกจากบทเจ้าของฉากเก่าที่กลับไปเยี่ยม
- เพิ่มการหักไอเทมของตัวเลือกอย่างเป็นธุรกรรม การแบ่งผลไม้จึงใช้ของจริงในกระเป๋า ไม่แจกความสัมพันธ์โดยไม่หักต้นทุน
- ส่งออกสัญญาข้อมูลครบทุก Node: บท สถานที่ ข้อความ เงื่อนไข ท่าทาง ตัวเลือก ผล รางวัล ปลายทาง NPC และคำสั่ง Cinematic พร้อมตัวตรวจอ้างอิงและเส้นทางที่เล่นถึงได้จริง
- เพิ่มข้อความตามข้อเท็จจริงของโลก เมื่อผลไม้ถูกเก็บ รากแตกใบ หรือเปิดทางน้ำแล้ว การกลับมาจะไม่อ้างว่าวัตถุยังอยู่ในสภาพก่อนเหตุการณ์ และไม่รันรางวัลซ้ำ

## 3. เนื้อเรื่องที่เพิ่ม

พิพมีวิธีช่วยสามแบบ ตามด้วยการแบ่งหรือเก็บผลไม้ ทางเลือกที่แบ่งใช้ผลไม้หนึ่งชิ้นจริง และพิพจดจำการกระทำนี้ การช่วยครั้งแรกและผลตอบแทนไม่สามารถรับซ้ำด้วยการย้อนเข้าเหตุการณ์

ARC 2 ตอนแรกเริ่มจากรับคำฝาก เตรียมเสบียงและเวท ออกตามป้ายเก่า ตรวจดินและร่องน้ำ ฟังร่องรอยในโพรง พบผู้ถักราก แล้วกลับมาหาคนที่รอฟัง ผู้เล่นใช้มือหรือเวทแก้ปัญหา ใช้ความสามารถนักสำรวจหรือผู้พิทักษ์ธรรมชาติ และใช้ความสัมพันธ์กับพิพเปิดทางผ่านอีกแบบได้ บทสรุปครอบครัว/ชุมชน/หอสมุดเดิมเปิดข้อสังเกตต่างกัน

ตอนนี้มีผลต่อฉากสามทาง: ประคองรากให้เป็นที่พัก, ทำป้ายเส้นทางที่เข้าถึงได้ หรือเก็บบันทึกความรู้ ผู้เล่นพักการรายงานแล้วกลับหมู่บ้านก่อน จากนั้นกลับมาทำต่อได้โดยไม่เปลี่ยนผลที่เลือกไว้หรือรับชุดเตรียมตัว/ของขวัญซ้ำ นี่คือการเดินทางตอนแรก ไม่ใช่การปิด ARC 2 ทั้งบทหรือสร้าง 12 ARC ครบแล้ว

## 4. ระบบเกมและ Manual File Save

ผู้ถักรากเป็น Encounter ใหม่ที่ประกาศจังหวะรวบรวมพลัง/เมล็ด/เถากวาด การร่ายน้ำโจมตีตรงจังหวะเถากวาดลดแรงปะทะลงได้ เวทสนับสนุนไม่ถูกนับเป็นการโต้ธาตุ ผู้เล่นใช้เวทที่ติดตั้งจริงและกลับสู่เหตุการณ์เดิมหลังสู้ หนีหรือแพ้ได้ตามเงื่อนไขของ Encounter

เพิ่มตัวอย่างเรียนและผสม Water กับ Bloom Ward จากวัตถุดิบที่ได้จริง สูตรเดิม 234 สูตรและ Recipe IDs คงเดิม ภาพเวทแยกจากการคำนวณผลต่อสู้ ไม่มีการเพิ่มสูตรเปล่าเพื่อให้จำนวนถึงเป้าหมาย

ข้อมูลอยู่ใน RAM เท่านั้น ส่งออก `.godseed` เมื่อกดเอง โหลดเมื่อเลือกไฟล์ ดูสรุป และยืนยัน File2/State2 คงเดิม เพิ่ม batchId เป็น metadata ที่รองรับการไม่มีค่านี้ในไฟล์เก่า บทของการเดินทางยังเป็นบทสองเมื่อกลับฉาก Hub ของบทแรก ไม่มี Auto Save, Cloud Save, การกู้คืนหลังรีเฟรช หรือการส่งเซฟขึ้นเซิร์ฟเวอร์
