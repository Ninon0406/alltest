# Way of Xian — Benchmark ที่ตรวจสอบได้

ตรวจเมื่อ 2026-11-06 UTC ตาม Owner V6 · สถานะ: **ศึกษาบางส่วน / ยังไม่ได้ทดลองเกมจริง** เอกสารนี้ไม่ใช่หลักฐานว่า GODSEED มีระบบตามต้นแบบแล้ว และไม่ให้คะแนนความสนุกหรือคุณภาพมือถือจากหน้าที่โหลดไม่ครบ

## วิธีตรวจและหลักฐาน

1. เปิด [หน้าเกม](https://way-of-xian.wox-game.workers.dev/) และ [สารานุกรม](https://way-of-xian.wox-game.workers.dev/wiki) ด้วย Playwright/Chromium ที่ viewport 390×844 และ touch ทั้งสอง URL ตอบเป็น `ERR_TUNNEL_CONNECTION_FAILED` ก่อนแสดงเกม นโยบายเครือข่ายของ executor เป็น restricted และไม่มี host นี้ใน allowlist ไม่เปลี่ยน proxy หรือหลบนโยบาย ดู [browser-attempts.json](evidence/browser-attempts.json)
2. ใช้เครื่องมือ web retrieval ที่มีแยกต่างหากเปิด URL เดิม ได้เพียง HTML shell: ชื่อเกม ข้อความกำลังโหลด ปุ่มธีม/ความเร็ว และส่วนหัวสารานุกรมพร้อมเมนู ค้นหา ภาษา และลิงก์กลับเกม เครื่องมือนี้ไม่ได้รัน interaction ของเกม
3. ค้นหาเฉพาะโดเมนทางการ พบผลที่ยืนยันส่วนหัว/ช่องค้นหาของ wiki แต่ไม่มีหน้าระบบย่อยที่ให้ข้อมูลเพียงพอในผลรอบนี้ ไม่อ่าน JavaScript bundle, source code หรือเอา asset ของเกมมาใช้

ผล: ไม่มี screenshot ของเกมที่ทดลองเล่นสำเร็จ ไม่มี account/session, จำนวนสาย/สูตร/กิจกรรม, เส้นทางจบ, ค่า FPS หรือข้อมูลเศรษฐกิจที่ตรวจยืนยันได้ ดู [web-observations.json](evidence/web-observations.json) ซึ่งบันทึกเฉพาะข้อสังเกตและแหล่งอ้างอิง ไม่เก็บเนื้อหาเว็บฉบับเต็ม

## สิ่งที่เห็นจริง จุดแข็ง และสิ่งที่ยังประเมินไม่ได้

| สิ่งที่เห็นใน HTML ที่เข้าถึงได้ | ข้อสังเกตที่รองรับ | ขอบเขตของข้อสรุป |
| --- | --- | --- |
| สารานุกรมมี URL แยกจากเกมและลิงก์กลับ | มีจุดเข้าอ่านข้อมูลแยกจากหน้าเล่น | ยังไม่ทราบความครบ/ถูกต้องของข้อมูลและการเชื่อมกับ state |
| Wiki มีเมนู ค้นหา และตัวเลือกภาษา | มีโครงสร้างสำหรับค้นข้อมูลหลายหน้าและหลายภาษา | ยังไม่ได้กดค้นหา สลับภาษา หรือทดสอบการไหลของจอบนมือถือ |
| หน้าเกมมีปุ่มธีมและระดับความเร็ว | มีตัวควบคุมการนำเสนอให้เลือก | ยังไม่ทราบว่าควบคุมเฉพาะ animation หรือเปลี่ยนเวลาของเกม และไม่ทราบขนาดพื้นที่สัมผัสจริง |

จุดแข็งที่พออ้างได้คือการแยกแหล่งความรู้และมีตัวควบคุมการนำเสนอในโครง HTML เท่านั้น ยังไม่สามารถระบุจุดอ่อนของ **ตัวเกม** อย่างเป็นธรรมได้ การโหลดไม่ผ่านใน executor ไม่ใช่หลักฐานว่าเว็บเสียหรือเล่นบนมือถือไม่ได้ ช่องว่างของการประเมินคือไม่มีการเล่นต่อเนื่องและไม่มีข้อมูลรายละเอียดใน wiki ที่เข้าถึงได้รอบนี้

## หัวข้อที่ Owner V6 ให้ศึกษา

ทุกแถวด้านล่างมีสถานะต้นแบบ **ยังไม่ยืนยัน** ข้อเสนอฝั่ง GODSEED เป็นการออกแบบของโครงการเอง ไม่ใช่การอ้างว่าต้นแบบทำเช่นนี้

| หัวข้อ | สิ่งที่ต้องตรวจบนต้นแบบเมื่อเข้าถึงได้ | ข้อเสนอสำหรับ GODSEED / หลักฐานที่ต้องมี |
| --- | --- | --- |
| เส้นทางชีวิต | วิธีเริ่ม เปลี่ยนสาย และผลเฉพาะสาย | เริ่มจากกิจกรรมที่เลือกเอง; แต่ละสายต้องมีการกระทำ/ข้อจำกัดต่างกันและเส้นทางทดสอบจริง |
| ความสามารถและการฝึกฝน | ต้นทุน เวลา และสิ่งปลดล็อก | ความเข้าใจธาตุ/รูปแบบเปิดทางเลือกใหม่ ไม่เพิ่มแต่ตัวเลข; มีบททดสอบและ fallback |
| สำนัก/กลุ่มอำนาจ | ชื่อเสียง เงื่อนไขเข้า ความขัดแย้ง | องค์กรต้นฉบับผูกกับความรู้และการช่วยเมือง; reputation เปลี่ยนผ่าน reducer เท่านั้น |
| ปรุงยา/ปรุงเวท | วัตถุดิบ สูตร ข้อผิดพลาด ผลของผลิตภัณฑ์ | สูตร deterministic ที่มีผลในเรื่องและการต่อสู้; validator ปฏิเสธสูตรโดยไม่กินของ |
| สร้างสิ่งของ | คุณสมบัติ การอัปเกรด และวงจรทรัพยากร | เพิ่มเมื่อมีเหตุการณ์ที่ใช้สิ่งของจริง ไม่สร้างรายการไอเทมที่ไม่มีผู้บริโภค |
| ร้านค้าและเศรษฐกิจ | ราคาแหล่งซื้อ/ขาย ภาวะขาดแคลน ป้องกันวงจรโกง | ราคาอิง world flags อย่างมีขอบเขต; ทดสอบเงิน/ของก่อนและหลัง transaction และผลจากภารกิจ |
| เดินทาง | เวลา ค่าใช้จ่าย จุดหมายและทางกลับ | ใช้ choice-driven routes/anchors เดิม; เงื่อนไขสถานที่และการกลับออกต้องตรวจได้ |
| ความสัมพันธ์ | NPC จำอะไร และความไว้ใจเปลี่ยนตัวเลือกใด | ผูกบทสนทนากับ fact tags/choice IDs เดิม; reward ร่วมให้ครั้งเดียวและเซฟคืนได้ |
| ข่าวลือ | ข้อมูลจริง/ผิด เงื่อนไข เวลาและที่มา | ข่าวลืออ้าง event ที่มีอยู่; AI เรียบเรียงได้แต่สร้าง state/รางวัลไม่ได้ |
| เหตุการณ์พิเศษและสถานที่ลับ | trigger, discoverability, ทางออก | มี hint ตามสถานะและ alternate solution; ไม่บังคับสู้ทุกปริศนา |
| โลกเปลี่ยนแปลง | ความเปลี่ยนแปลงข้ามวัน/เมือง/NPC | ผลการช่วยสวนหรือค้นทางปรากฏเป็นภาพ/แหล่งของ/บทพูดในครั้งถัดไป ไม่ใช่ข้อความครั้งเดียว |
| UI มือถือและข้อมูลจำนวนมาก | hierarchy, scroll, touch, ชื่อสถานะและการย้อนกลับ | ภาพ/เรื่องเป็นแกน เปิดรายละเอียดเมื่อขอ; ตรวจ 10 viewport, touch/keyboard และอุปกรณ์จริงแยกกัน |
| กิจกรรมต่อเนื่อง | ทางเลือกหลังบทสรุป การพัก และ pacing | ทุกช่วงมีเป้าหมาย–การตัดสินใจ–ผลตอบกลับ–บทสรุปย่อย; ไม่ใช้กิจกรรมวนรับของเป็นตัวแทนเนื้อหา |

## การเปรียบเทียบที่ทำได้ตอนนี้

GODSEED มีหลักฐานจาก source/tests ของ choice-driven scene graph, การผสมเวท, combat intent และ Manual File Save ตามรายงานโครงการ ส่วนความกว้างของชีวิต/เศรษฐกิจ/ข่าวลือของ Way of Xian ยังไม่มีหลักฐานการเล่นในรอบนี้ จึง **เปรียบเทียบจำนวนระบบหรือประกาศว่าเทียบเท่า/เหนือกว่าไม่ได้**

สิ่งที่นำมาใช้ได้ทันทีโดยไม่คัดลอกคือแยกคำแนะนำออกจากพื้นที่เล่น เพิ่มการค้นข้อมูลตามบริบท และวัดว่าผู้เล่นเห็นกิจกรรมถัดไปได้จากสถานะจริงหรือไม่ ห้ามถือว่าแค่เพิ่มเมนูเป็นความก้าวหน้าของระบบเกม

## งานตรวจต่อ

เมื่อเครื่องมือเข้าถึงเว็บที่ได้รับอนุญาตได้ ให้บันทึกหนึ่ง session ตั้งแต่เริ่ม เลือกสาย ฝึก ใช้ทรัพยากร/ซื้อขาย พบ NPC เดินทาง และกลับไปเห็นผลเดิม พร้อมวัด UI มือถือจริง แล้วจึงแทนที่รายการ “ยังไม่ยืนยัน” ด้วยหลักฐาน ไม่ต้องหยุดการสร้างเนื้อหา GODSEED เพื่อรอ benchmark นี้
