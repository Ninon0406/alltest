# GODSEED: The World That Remembers

เกม Pixel Art RPG ภาษาไทย ควบคุมด้วยตัวเลือก สร้างเวท และต่อสู้ผลัดเทิร์น ไม่ต้องใช้ API Key

สถานะโค้ด 0.6.0 (release candidate PR#10): **เมล็ดแรก — vertical slice** เล่นตั้งแต่ตื่น รับวัตถุดิบ เรียนกับคุโร ผสมวายุดารานำวิถี ต่อสู้ต้นอ่อน เก็บโน้ต แล้วกลับหมู่บ้านได้ หลังผสมเวทแรกยังฝึกกับภูตของคุโรหรือยุติการฝึกได้ นำเบาะแสจากป่ากลับไปให้คุโรเพื่อรับส่วนผสมเวทไฟ แล้วผสมเองในโต๊ะเวท สวนมาเรนมีของสำหรับเวทเยียวยา เพิ่มหอสมุดของไอรากับลำธารในเมนู “สถานที่อื่น” ค้นคว้า ผสมเวทน้ำ/เสียงสะท้อน ต่อสู้กับวิญญาณละอองธารา หรือช่วยกระดิ่งผ่านทางไม่ต่อสู้ได้ ภาพมีฉากหลายชั้น6แห่ง ผู้เล่น11ท่า ไอราและวิญญาณน้ำวาดใหม่ แต่ยังเป็น original procedural prototype และยังไม่ใช่บทแรกครบสามบทสรุป

รอบภาพใหม่เพิ่มต้นไม้ใหญ่และลานน้ำพุแบบแยกเลเยอร์ ท่ายืนสี่ทิศ เส้นทางที่ตรวจ Collision และการนั่งพักที่โหลดกลับมาได้ ถ้ามีเซฟเดิม ไปที่จัตุรัส → “สถานที่อื่น” → “แวะใต้ต้นเมล็ด” ภาพยังต้นแบบ; ตารางความพร้อม9ด้านของทั้ง10สถานที่อยู่ใน Roadmap ภาพอ้างอิงเก็บเพื่อพัฒนาและไม่ถูกส่งไปกับเกม

เลือก “ไปโรงช่างของคุโร” → “ขอเรียนการผสมเวท” → “ทดลองสูตรแรกจากของที่มี” → “ผสมและค้นพบเวท” จากนั้นไปชายป่าเพื่อทดลองต่อสู้ มีทางเลี่ยงการต่อสู้และกลับมาเตรียมตัวได้

บันทึกอัตโนมัติใน IndexedDB ของอุปกรณ์ กู้สำเนา นำเข้า หรือส่งออกไฟล์เซฟได้จากหน้าแรกและเมนู “บันทึก” ไฟล์ใหม่มี checksum และยังรับไฟล์เซฟรุ่นเดิมได้ การเริ่มใหม่ขอคำยืนยันและเก็บเรื่องราวเดิมไว้ให้กลับมาเล่นต่อ

หากบันทึกลงอุปกรณ์ไม่ได้ จะมีแถบเตือน “เล่นชั่วคราวในหน่วยความจำ” เกมยังเล่นต่อได้ แต่ปิดหรือรีโหลดหน้าแล้วความคืบหน้าอาจหาย ให้กด “ดาวน์โหลดสำเนาเซฟ” หรือ “ลองบันทึกลงอุปกรณ์อีกครั้ง” เมื่อพื้นที่พร้อม ไม่มี cloud sync

## พัฒนาและทดสอบ

Node 24: `npm ci --prefix GODSEED` แล้ว `npm --prefix GODSEED run test:all` และ `npm --prefix GODSEED run test:e2e` (`CHROMIUM_PATH` กำหนด Chromium ในเครื่อง; CI ใช้ browser ของ Playwright)

`npm run dev` เปิด development server, `npm run build` build และ stage เว็บไซต์ที่ root เพื่อรองรับ Pages `main:/` ด้วย ไม่แก้ไฟล์ compiled ใน `assets/` เอง

โปรเจกต์ REBORN ถูกนำออกจาก working tree ตามคำสั่งเจ้าของล่าสุด ไม่ใช่ระบบเซฟเดียวกับ GODSEED

เซฟเกมใช้ schema2 (ตั้งแต่รุ่น0.2.0) โดยย้ายจากV1และเก็บต้นฉบับก่อนเขียนครั้งแรก ตัวตน/seed/ความคืบหน้าไม่ถูกสุ่มใหม่ XP ที่แสดงยังไม่ใช่ระบบเลื่อนระดับอัตโนมัติ

ตรวจปริมาณเนื้อหาจากโค้ดด้วย `npm --prefix GODSEED run inspect:content` ใช้กฎเดียวกันระหว่างปุ่มกับระบบเพื่อแสดงเหตุผลของทางเลือกที่ยังล็อก เก็บของลำธารได้ตามวันในเกม การฟังกระดิ่งไม่ล้างผลการช่วยที่ทำไว้ก่อนหน้า

โต๊ะผสมแสดงตัวอย่างและวัตถุดิบที่ขาดก่อนยืนยัน สมุดเวทกรองธาตุ/ประเภท/MP และถอดเวทได้โดยไม่ลืมสูตร ถอดแล้วช่องที่เหลือเลื่อนขึ้น; ไม่มีเวทติดตั้งก็ใช้ประกายพื้นฐานและตั้งรับได้
