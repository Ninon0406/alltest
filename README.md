# GODSEED: The World That Remembers

เกม Pixel Art RPG ภาษาไทย ควบคุมด้วยตัวเลือก สร้างเวท และต่อสู้ผลัดเทิร์น ไม่ต้องใช้ API Key

สถานะโค้ด 0.6.0: **เมล็ดแรก — vertical slice** เล่นตั้งแต่ตื่น รับวัตถุดิบ เรียนกับคุโร ผสมวายุดารานำวิถี ต่อสู้ต้นอ่อน เก็บโน้ต แล้วกลับหมู่บ้านได้ หลังผสมเวทแรกยังฝึกกับภูตของคุโรหรือยุติการฝึกได้ นำเบาะแสจากป่ากลับไปให้คุโรเพื่อรับส่วนผสมเวทไฟ แล้วผสมเองในโต๊ะเวท สวนมาเรนมีของสำหรับเวทเยียวยา เพิ่มหอสมุดของไอรากับลำธารในเมนู “สถานที่อื่น” ค้นคว้า ผสมเวทน้ำ/เสียงสะท้อน ต่อสู้กับวิญญาณละอองธารา หรือช่วยกระดิ่งผ่านทางไม่ต่อสู้ได้ ภาพมีStageหลายชั้น6แบบ/7สถานที่ภาพ ผู้เล่น11ท่า ไอราและวิญญาณน้ำวาดใหม่ แต่ยังเป็น original procedural prototype และยังไม่ใช่บทแรกครบสามบทสรุป

รอบภาพใหม่เพิ่มต้นไม้ใหญ่และลานน้ำพุแบบแยกเลเยอร์ ท่ายืนสี่ทิศ เส้นทางที่ตรวจ Collision และการนั่งพักที่โหลดกลับมาได้ ถ้ามีเซฟเดิม ไปที่จัตุรัส → “สถานที่อื่น” → “แวะใต้ต้นเมล็ด” ภาพยังต้นแบบ; ตารางความพร้อม9ด้านของทั้ง10สถานที่อยู่ใน Roadmap ภาพอ้างอิงเก็บเพื่อพัฒนาและไม่ถูกส่งไปกับเกม

เลือก “ไปโรงช่างของคุโร” → “ขอเรียนการผสมเวท” → “ทดลองสูตรแรกจากของที่มี” → “ผสมและค้นพบเวท” จากนั้นไปชายป่าเพื่อทดลองต่อสู้ มีทางเลี่ยงการต่อสู้และกลับมาเตรียมตัวได้

บันทึกอัตโนมัติใน IndexedDB ของอุปกรณ์ กู้สำเนา นำเข้า หรือส่งออกไฟล์เซฟได้จากหน้าแรกและเมนู “บันทึก” ไฟล์ใหม่มี checksum และยังรับไฟล์เซฟรุ่นเดิมได้ การเริ่มใหม่ขอคำยืนยันและเก็บเรื่องราวเดิมไว้ให้กลับมาเล่นต่อ

หากบันทึกลงอุปกรณ์ไม่ได้ จะมีแถบเตือน “เล่นชั่วคราวในหน่วยความจำ” เกมยังเล่นต่อได้ แต่ปิดหรือรีโหลดหน้าแล้วความคืบหน้าอาจหาย ให้กด “ดาวน์โหลดสำเนาเซฟ” หรือ “ลองบันทึกลงอุปกรณ์อีกครั้ง” เมื่อพื้นที่พร้อม ไม่มี cloud sync

### ชุดภาพอ้างอิงและสถานที่ (รอบ12)

ภาพอ้างอิงเจ้าของ10แห่งอยู่ใน `assets/reference/godseed/` สำหรับพัฒนาเท่านั้น Asset ในเกมวาดใหม่ที่ `GODSEED/public/assets/art-v5/` ไม่ใช้ภาพเต็มเป็นพื้นหลัง เลือกดู [หลักฐานภาพก่อน–หลัง](GODSEED/docs/evidence/session12/README.md) และตาราง9ด้านต่อสถานที่ใน Master Roadmap

ตรวจด้วย `npm --prefix GODSEED run validate:references` รวมใน CI และตรวจซ้ำหลัง staging; Vite dist/Actions Artifact ไม่มี Concept Files รักษาไฟล์ Client รุ่นเก่าไว้สำหรับ HTML ที่ cache

การตั้งค่า Pages Source ปัจจุบันยังเป็น legacy `main:/` Integration อ่านค่าได้แต่แก้เป็น `workflow` ไม่ได้ (GitHub API403) Workflow เผยแพร่เดิมยังใช้งานได้ การรับรองว่าแยก References ออกจาก Artifact หมายถึง Actions/Vite; Legacy Archive อาจมีไฟล์จาก Repository ที่เกมไม่ได้โหลด หากต้องการให้มีเส้นทางเผยแพร่เดียว: GitHub บนโทรศัพท์ → Repository → Settings → Pages → Build and deployment → Source → GitHub Actions ไม่ต้องรัน Terminal
