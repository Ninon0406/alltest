# GODSEED — คู่มือเริ่มจากไฟล์รวม (มือถือเท่านั้น)

ไฟล์ชุดนี้รวมคำสั่งเริ่มเกม สเปกเกม คำสั่งพัฒนาต่อ ชุด Codex Skills ทั้งสิบ และคู่มือเดิมไว้ใน ZIP เดียว

## สำคัญ
- อย่าให้ Codex สร้างเกมใหม่ทับโปรเจกต์ที่มีอยู่
- ติดตั้งสกิลก่อนโดยให้ Codex ตรวจ `.agents/skills/` และ `AGENTS.md` ที่มีอยู่ ถ้ามีให้ merge อย่างระมัดระวัง
- `01_CODEX_START.md` = เริ่มโปรเจกต์ (ใช้ครั้งแรก)
- `02_GODSEED_MASTER_SPEC.md` = ข้อกำหนดเกม (อ้างอิงหลักทุกครั้ง)
- `03_CODEX_CONTINUE_FOREVER.md` = ใช้ส่งซ้ำใน Codex รอบถัดไปหลังงานเดิมบันทึก/merge แล้ว
- `.agents/skills/` = Skill Pack 10 ชุด ให้ Codex อ่านและใช้กับงานตามประเภท
- `GODSEED_INSTALL_ONE_PROMPT.md` = วิธีสำรองในกรณีจำเป็นต้องสร้างสกิลด้วยข้อความ

## วิธีลงไฟล์จากโทรศัพท์
1. ถ้า Codex รับ ZIP เป็นไฟล์แนบ ให้อัปโหลด ZIP แล้วสั่งให้แตกไฟล์ลง repository โดยรักษาโครงสร้างทุกโฟลเดอร์
2. ถ้าแนบ ZIP ไม่ได้ ให้เข้าหน้าเว็บ GitHub repository ผ่าน Safari/Chrome และอัปโหลด ZIP ไว้ที่ root ของ repo (เมื่อบัญชี/หน้าเว็บรองรับการอัปโหลด) จากนั้นให้ Codex แตกไฟล์จาก ZIP ภายใน repo โดยใช้เครื่องมือใน environment
3. ห้ามเพิ่งเริ่มสร้างเกมระหว่างแตกไฟล์ ให้ตรวจและติดตั้ง 10 skills ก่อน
4. หลังจากนั้นเริ่ม Codex งานใหม่ สั่งอ่าน `01_CODEX_START.md` + `02_GODSEED_MASTER_SPEC.md` แล้วลงมือสร้างเกม
5. ระหว่างพัฒนาต่อ สั่งอ่าน `03_CODEX_CONTINUE_FOREVER.md` ใน repository

## Prompt สั้นสำหรับ Codex หลังอัปโหลด ZIP

```text
ไฟล์ GODSEED_ALL_IN_ONE.zip อยู่ใน repository หรือแนบอยู่ในงานนี้ กรุณาตรวจสอบว่ามีอยู่จริง ก่อนเริ่มงาน
แตกไฟล์อย่างปลอดภัยลง repository ปัจจุบัน โดยตรวจไฟล์เดิมทั้งหมดก่อนและห้ามเขียนทับงานที่มีความคืบหน้าแล้ว
ติดตั้ง/merge .agents/skills/ 10 ชุด และตรวจ SKILL.md กับ AGENTS.md ถ้ามี อย่าสร้างซ้ำโดยไม่จำเป็น
คง 01_CODEX_START.md, 02_GODSEED_MASTER_SPEC.md, 03_CODEX_CONTINUE_FOREVER.md ใน root ของ repository
ตรวจ manifest ว่าทุกไฟล์สมบูรณ์ สรุปผลเป็นภาษาไทย บันทึก changes/PR ตามสิทธิ์ที่มี
รอบนี้ติดตั้งเอกสารและ skills เท่านั้น ไม่ต้องสร้างเกมจนกว่าผมจะสั่งเริ่ม
```

## หาก ZIP ดาวน์โหลดไม่ได้ในแอป ChatGPT
- ลองแตะลิงก์ค้างแล้วเลือกเปิดใน Safari/Chrome หรือลองเปิดบทสนทนาบน chatgpt.com ผ่านเบราว์เซอร์
- ตรวจแอป Files > Downloads
- ทางเลือกไม่ต้องดาวน์โหลดเลย: อนุญาตให้ ChatGPT ใช้ GitHub connector อัปโหลดเอกสารลง repo ที่คุณระบุให้ได้ หากเครื่องมือและสิทธิ์เชื่อมต่อรองรับ
