# Annual pacing reference — 0.5.0

The latest user message requests fewer mandatory two-option interruptions, occasional multi-option decisions, and annual activity selection inspired by https://1in8b.life/th/. The user then supplied screenshots and videos https://www.youtube.com/watch?v=JlhwMECfy0Q and https://www.youtube.com/watch?v=_1NKzKFWjAg. This explicit request supersedes the old opening-year mandatory choice quota.

The screenshots show age/year controls, pause/speeds, seek-next-decision, a status/identity column, annual focus and journal, family and life-history cells, plus occasional three/four-option decision cards. REBORN adopts that interaction pattern with its own navy/gold fantasy world, original local artwork, saved birth/family records and existing time/career/route mechanics. It adds 1/2/5-year manual steps and 4–5-option crossroads. No reference text, sprites, world statistics or simulation code were copied. No fake players, peer births or global counters were added.

Access limitation: direct requests to 1in8b.life were rejected by this environment's network proxy (CONNECT 403). The live reference and linked videos were not watched or audited. Implementation is based on the user-provided screenshots and written direction. The environment draft preserves the existing network settings and adds only 1in8b.life; it remains a draft requiring environment review/save/publication, not an applied runtime change. Gameplay implementation/deployment does not depend on opening that domain.

Pacing rules: yearly focus persists until changed; minor existing responses resolve automatically and are explicitly tagged in the journal. Big decisions stop automatic/multi-year advancement. Career prompts are at least two years apart; age-range life milestones allow imported older lives to continue without invented past chapters. Awakening can be postponed or completed by one approach using the actual remaining seven-stage implementation. A detailed reader and original chapters remain optional.

Autoplay defaults off and is never stored in a save. There is no offline advancement. Annual play delegates real practice/wages/rest/travel to existing rules and summarizes only actions actually executed; it does not grant a whole year's rewards for a partial year. Equipment, natural mortality, ascension and full NPC relationships remain future work.
