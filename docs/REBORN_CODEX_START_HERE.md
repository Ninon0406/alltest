# คำสั่งสั้นสำหรับเริ่ม Codex — REBORN

ใช้ Repository `Ninon0406/alltest` (branch ล่าสุด) และอ่านไฟล์แนบ `REBORN_CODEX_ULTIMATE_DIRECTIVE.md` ทั้งหมดก่อนลงมือ

นี่คือข้อกำหนดหลักของโปรเจกต์ ให้ยึดร่วมกับ `AGENTS.md` ใน repository โดยข้อกำหนดใหม่ด้าน direction, เวลา, อาชีพ และสัดส่วนเนื้อเรื่องใช้แทนข้อเก่าที่ขัดกัน แต่อย่าทำลายระบบที่ใช้งานได้แล้ว

**ลงมือแก้ไขไฟล์เกมจริงทันที ไม่หยุดที่แผน:** ตรวจ HEAD, ตรวจการ build/deploy ของ `app.html`/`src` และ Pages ที่ `/alltest/`, สร้าง checklist แล้วทำ P0/P1 (ระบบเวลา/อายุ, เนื้อเรื่องเด็ก, UI status, equal births) พร้อม unit/E2E tests, build, update manifest และ commit/checkpoint ที่ปลอดภัย

จากนั้นดำเนิน milestone ที่เหลือตาม dependency เท่าที่การทำงานครั้งนี้รองรับ เน้นคุณภาพมากกว่ารายงานจำนวนปลอม ถ้าทำไม่ครบในหนึ่ง execution ให้บันทึก `docs/NEXT_CODEX_TASK.md` ระบุไฟล์ จุดค้าง tests และ task ถัดไปอย่างชัดเจน ห้ามกล่าวอ้างว่าทำงานต่อในเบื้องหลัง

ผู้ใช้อนุญาตให้พัฒนาและเผยแพร่เว็บไซต์นี้สู่สาธารณะแล้ว แต่การเปลี่ยนสิทธิ์หรือการดำเนินการที่แพลตฟอร์มบังคับยืนยันให้ขออนุมัติตามปกติ ไม่ใช้ API เสียเงิน ไม่ลบข้อมูลเดิมหรือ force push

เมื่อเสร็จให้สรุปภาษาไทย: ระบบที่ทำงานได้จริง, ผลทดสอบ, จำนวน content authored/reachable, commit, URL live และความมั่นใจจากการตรวจเว็บจริง, ข้อบกพร่อง และงานถัดไป
