3.5 การหาอนุพันธ์ฟังก์ชันพีชคณิต & กฎลูกโซ่

ความยาก: ★★☆☆☆
สูตรหลักที่ต้องจำ:
• d/dx(xⁿ) = n·xⁿ⁻¹
• d/dx(uⁿ) = n·uⁿ⁻¹ · (du/dx) [กฎลูกโซ่]
• d/dx(หน้า·หลัง) = หน้า·ดิฟหลัง + หลัง·ดิฟหน้า
• d/dx(บน/ล่าง) = (ล่าง·ดิฟบน - บน·ดิฟล่าง) / ล่าง²

🎯 รูปแบบคำตอบที่ต้องการ:

ให้ตอบในรูป f'(x) = ... หรือ dy/dx = ... โดยจัดรูปเศษส่วน จัดการกำลังติดลบให้อยู่ในรูปพจน์บวก หรือดึงตัวองค์ประกอบร่วมออกให้เรียบร้อยที่สุด

💡 วิธีคิดและขั้นตอนการทำแบบมองปุ๊บแก้ได้ปั๊บ

  1. มองรูปแบบโจทย์: ถ้าเห็นกลุ่มก้อนยกกำลัง เช่น y = (3x² - 5)⁴ ให้มองทั้งก้อนเป็น u จะได้ y = u⁴
  2. ดิฟชั้นนอก: เอาเลขชี้กำลังลงมาคูณข้างหน้าแล้วลดกำลังลง 1 จะได้ 4(3x² - 5)³
  3. ดิฟไส้ใน (ดิฟ u): ดริฟก้อนข้างใน (3x² - 5) ได้ 6x แล้วเอามาคูณต่อท้าย
  4. รวมพจน์ตอบ: dy/dx = 4(3x² - 5)³ · (6x) = 24x(3x² - 5)³ ตอบได้เลย!

3.6 อนุพันธ์อันดับสูง (Higher-Order Derivatives)

ความยาก: ★★☆☆☆
สัญลักษณ์ & สูตรสำคัญ:
• อนุพันธ์อันดับ 1: f'(x) = dy/dx = v(t) (ความเร็ว)
• อนุพันธ์อันดับ 2: f''(x) = d²y/dx² = a(t) (ความเร่ง)
• อนุพันธ์อันดับ n: f⁽ⁿ⁾(x) = dⁿy/dxⁿ
• รูปแบบทั่วไป: หาแบบรูปแบบซ้ำ (Pattern Recognition)

🎯 รูปแบบคำตอบที่ต้องการ:

1. ตอบค่าตัวเลขเฉพาะ เช่น f''(2) = 18
2. ตอบในรูปสูตรทั่วไป f⁽ⁿ⁾(x) ที่ติดในเทอมของ n

💡 วิธีการทำข้อสอบหา f⁽ⁿ⁾(x) ลัดขั้น

  1. ทำดิฟไล่ลำดับ 3 ครั้งแรก: หา f'(x), f''(x), และ f'''(x) ออกมาก่อน
  2. สังเกตรูปแบบ (Pattern): ดูเครื่องหมาย (+/-), ตัวเลขสัมประสิทธิ์, และพลังกำลังของ x
  3. สร้างฟังก์ชัน n: เขียนความสัมพันธ์ในรูป (-1)ⁿ, n!, หรือ 2ⁿ
  4. สรุปตอบ: เขียน f⁽ⁿ⁾(x) = [สูตรที่ได้] ตอบได้อย่างมั่นใจ

3.7 การหาอนุพันธ์ของฟังก์ชันโดยปริยาย (Implicit)

ความยาก: ★★★☆☆
สูตร/กฎทองคำ:
• ดิฟเทอม x: ดิฟตามปกติ d/dx(xⁿ) = n·xⁿ⁻¹
• ดิฟเทอม y: ดิฟแล้วต้องคูณ (dy/dx) ติดไว้เสมอ!
• d/dx(yⁿ) = n·yⁿ⁻¹ · (dy/dx)
• d/dx(x·y) = x·(dy/dx) + y(1) [กฎคูณ]

🎯 รูปแบบคำตอบที่ต้องการ:

ย้ายข้างให้ฝั่งซ้ายเหลือ dy/dx ตัวเดียว ส่วนฝั่งขวาเป็นเศษส่วนที่ติดทั้งตัวแปร x และ y

💡 ขั้นตอนการแก้โจทย์สมการปน x และ y

  1. เทก d/dx ทั้งสองข้าง: ใส่ d/dx กระจายเข้าไปทุกพจน์ของสมการ
  2. ดิฟทีละพจน์: เจอตัวแปร y ให้ดิฟปกติแล้วพ่วง dy/dx ท้ายพจน์นั้น
  3. ย้ายกลุ่ม dy/dx: ย้ายพจน์ที่มี dy/dx มาไว้ฝั่งซ้าย ย้ายพจน์ไม่มี dy/dx ไปฝั่งขวา
  4. ดึงตัวองค์ประกอบร่วม: ดึง dy/dx ออกมาแล้วเอาตัวคูณย้ายไปหารฝั่งขวา ตอบทันที

3.8 อนุพันธ์ฟังก์ชันอดิสัย (Trig, Expo, Log)

ความยาก: ★★★★☆
สูตรตระกูลอดิสัยที่ต้องท่องจำ:
• d/dx(sin u) = cos u · (du/dx)
• d/dx(cos u) = -sin u · (du/dx)
• d/dx(eᵘ) = eᵘ · (du/dx)
• d/dx(ln u) = (1/u) · (du/dx)

🎯 รูปแบบคำตอบที่ต้องการ:

ตอบในรูป f'(x) โดยจัดรูปให้มุมตรีโกณหรือกำลัง e อยู่ในรูปอย่างง่ายที่สุด

💡 วิธีจำและทางลัดการทำโจทย์ผสม

  1. สูตรดิฟตรีโกณที่มี 'c' นำหน้า: (cos, cot, cosec) ดิฟแล้วจะได้ค่าติดลบเสมอ
  2. ดิฟ e ยกกำลังไส้ u: ลอกตัวเดิมออกมาก่อนเป็น eᵘ แล้วดริฟไส้ u คูณปิดท้ายเสมอ
  3. ดิฟ ln(ไส้ u): เอาไส้ u ไปไว้ข้างล่าง แล้วเอาดิฟไส้ (du/dx) ไปไว้ข้างบนเป็น du/u

3.9 สมการเส้นสัมผัสโค้ง & เส้นปกติ (Tangent & Normal)

ความยาก: ★★★☆☆
สูตรเส้นตรง & ความชัน:
• ความชันเส้นสัมผัส: m_tan = f'(x₀)
• ความชันเส้นปกติ: m_nor = -1 / m_tan
• สมการเส้นตรง: y - y₀ = m(x - x₀)

🎯 รูปแบบคำตอบที่ต้องการ:

สมการเส้นตรงในรูปมาตรฐาน Ax + By + C = 0 หรือรูปความชัน y = mx + c

💡 ขั้นตอนการสร้างสมการแบบไม่หลงทาง

  1. หาจุด (x₀, y₀): ถ้าโจทย์ให้เฉพาะ x₀ ให้แทน x₀ ลงใน f(x) เพื่อหาค่า y₀ ออกมาก่อน
  2. หาความชัน m_tan: ดิฟ f(x) ได้ f'(x) แล้วแทนค่า x₀ ลงไป ได้ค่าความชัน m
  3. ถ้าโจทย์ถามเส้นปกติ: ปรับความชันเป็น m_nor = -1/m
  4. เข้าสูตรเส้นตรง: แทนจุดและ m ลงใน y - y₀ = m(x - x₀) แล้วจัดรูปตอบ

3.10 อัตราเกี่ยวเนื่อง (Related Rates)

ความยาก: ★★★★☆
หลักการสำคัญ:
• ตัวแปรทุกตัวเปลี่ยนตามเวลา t
• ดิฟเทียบ t ทั้งสองข้าง (d/dt)
• ปริมาตรกรวย: V = (1/3)πr²h
• พีทาโกรัส: x² + y² = z²

🎯 รูปแบบคำตอบที่ต้องการ:

ค่าตัวเลขเดี่ยวๆ พร้อมหน่วย เช่น dV/dt = 12π cm³/s (ระวังเครื่องหมาย + เพิ่มขึ้น, - ลดลง)

💡 ขั้นตอนแก้โจทย์ปัญหาอัตราเกี่ยวเนื่อง

  1. วาดภาพ & ตั้งตัวแปร: กำหนดตัวแปรที่เปลี่ยนแปลงตามเวลา t
  2. สร้างสมการเชื่อมโยง: เขียนสูตรเรขาคณิตที่เชื่อมตัวแปรเหล่านั้น
  3. ลดตัวแปรเหลือ 1 ตัว (ถ้าจำเป็น): เช่น ใช้สามเหลี่ยมคล้ายหา r ในรูป h
  4. ดิฟเทียบ t (d/dt): แล้วแทนค่าตัวเลขที่โจทย์กำหนด คำนวณหาอัตราการเปลี่ยน

3.11 ค่าสุดขีดและการประยุกต์ (Extreme Values)

ความยาก: ★★★★☆
เงื่อนไขตรวจสอบ:
• จุดวิกฤต (Critical Point): f'(x) = 0
• f''(c) > 0 ➔ ได้จุดต่ำสุดสัมพัทธ์
• f''(c) < 0 ➔ ได้จุดสูงสุดสัมพัทธ์

🎯 รูปแบบคำตอบที่ต้องการ:

1. จุดสูงสุด/ต่ำสุด: ตอบเป็นคู่อันดับ (x, y)
2. ค่าสูงสุด/ต่ำสุด: ตอบเฉพาะค่า y = f(x)

💡 วิธีหาจุดสูงสุด/ต่ำสุดอย่างรวดเร็ว

  1. จับ f'(x) = 0: แก้สมการหาค่า x จะได้ค่าวิกฤต (Critical values)
  2. ทดสอบด้วย f''(x): นำค่า x ไปแทนใน f''(x) ดูเครื่องหมายเพื่อสรุปว่าสูงหรือต่ำ
  3. ถ้ามีช่วงปิด [a, b]: ต้องนำปลายช่วง a และ b ไปแทนใน f(x) เพื่อหาค่าสัมบูรณ์ด้วย

4.1 ปริพันธ์ไม่จำกัดเขต & เทคนิคเปลี่ยนตัวแปร u

ความยาก: ★★★☆☆
สูตรอินทิเกรตพื้นฐาน:
• ∫ xⁿ dx = (xⁿ⁺¹ / (n+1)) + C [n ≠ -1]
• ∫ (1/x) dx = ln|x| + C
• ∫ eˣ dx = eˣ + C
• ∫ uⁿ du = (uⁿ⁺¹ / (n+1)) + C

🎯 รูปแบบคำตอบที่ต้องการ:

ฟังก์ชันของ x และต้องบวกค่าคงตัว + C ต่อท้ายเสมอ! (ถ้าลืม + C จะถูกหักคะแนน)

💡 วิธีเลือก u เพื่อเปลี่ยนตัวแปรให้ตัดกันได้

  1. มองหาตัวแปร u: เลือก u จากก้อนที่อยู่ใต้วงเล็บยกกำลัง หรือก้อนที่ดิฟแล้วได้อีกพจน์
  2. ดิฟหา du: เช่น ให้ u = x² + 1 จะได้ du = 2x dx ➔ dx = du / (2x)
  3. แทนค่าเปลี่ยน dx เป็น du: ตัวแปร x จะตัดกันหมด เหลือเฉพาะตัวแปร u
  4. อินทิเกรต แล้วแทน u กลับ: เปลี่ยน u กลับเป็นเทอมของ x แล้วบวก + C ตอบทันที

4.2 ปริพันธ์จำกัดเขต & การหาพื้นที่ใต้โค้ง

ความยาก: ★★★★☆
สูตรการคำนวณ:
• ∫ₐᵇ f(x) dx = [F(x)]ₐᵇ = F(b) - F(a)
• พื้นที่ใต้โค้ง: A = ∫ₐᵇ |f(x)| dx
• พื้นที่ระหว่างเส้นโค้ง: ∫ₐᵇ (บน - ล่าง) dx

🎯 รูปแบบคำตอบที่ต้องการ:

1. ปริพันธ์จำกัดเขต: ตัวเลข (เป็นได้ทั้ง +, -, 0)
2. พื้นที่ (Area): ต้องเป็นจำนวนบวกเสมอ! (หน่วย: ตารางหน่วย)

💡 เทคนิคหาพื้นที่ป้องกันการคำนวณผิด

  1. หาจุดตัดแกน x (f(x) = 0): ตรวจสอบว่ากราฟตัดแกน x ในช่วง [a, b] หรือไม่
  2. ถ้ากราฟตัดแกน x: ให้แยกช่วงอินทิเกรต แล้วใส่ค่าสัมบูรณ์ |...| ในช่วงที่อยู่ใต้แกน
  3. ถ้าหาพื้นที่ระหว่าง 2 กราฟ: ให้เอา (สมการกราฟบน - สมการกราฟล่าง) แล้วค่อยอินทิเกรต

สรุปหัวใจสำคัญ & ข้อควรระวังในห้องสอบ 🎯

ข้อผิดพลาดที่มักทำให้โดนหักคะแนนในข้อสอบแคลคูลัสที่ต้องระวังเป็นพิเศษ

จุดผิดบ่อยในการดิฟ

• ลืมดิฟไส้ในเมื่อใช้กฎลูกโซ่
• ดิฟผลคูณผิด (ไปดิฟหน้า × ดิฟหลัง)
• ดิฟ y ในฟังก์ชันปริยายแล้วลืมพ่วง dy/dx

จุดผิดบ่อยในการอินทิเกรต

• ลืม + C ในปริพันธ์ไม่จำกัดเขต
• แทนค่า F(b) - F(a) ผิดเครื่องหมายลบ
• หาพื้นที่ใต้แกน x แล้วลืมเปลี่ยนเป็นค่าบวก

รูปแบบการตอบ

• กำหนดสัญลักษณ์ f'(x), dy/dx ให้ชัดเจน
• จัดรูปเศษส่วนและกำลังติดลบให้เรียบร้อย
• ใส่นามหน่วยในโจทย์ประยุกต์เสมอ
