สูตรการหาอนุพันธ์และปริพันธ์ (สูตรที่ **ให้** ในข้อสอบปลายภาค)

พิมพ์แนบมาหลังปกข้อสอบ

สูตรการหาอนุพันธ์ที่ให้มา (16 สูตร)

1. d/dx(sin u) = cos u (du/dx)

2. d/dx(cos u) = -sin u (du/dx)

3. d/dx(tan u) = sec² u (du/dx)

4. d/dx(sec u) = sec u tan u (du/dx)

5. d/dx(cot u) = -csc² u (du/dx)

6. d/dx(csc u) = -csc u cot u (du/dx)

7. d/dx(arcsin u) = 1/√(1-u²) (du/dx)

8. d/dx(arccos u) = -1/√(1-u²) (du/dx)

9. d/dx(arctan u) = 1/(1+u²) (du/dx)

10. d/dx(arccot u) = -1/(1+u²) (du/dx)

11. d/dx(arcsec u) = 1/(|u|√(u²-1)) (du/dx)

12. d/dx(arccsc u) = -1/(|u|√(u²-1)) (du/dx)

13. d/dx(log_a |u|) = 1/(u ln a) (du/dx)

14. d/dx(aᵘ) = aᵘ ln a (du/dx)

15. d/dx(ln|u|) = (1/u) (du/dx)

16. d/dx(eᵘ) = eᵘ (du/dx)

สูตรการหาปริพันธ์ที่ให้มา (17 สูตร)

1. ∫ uⁿ du = (uⁿ⁺¹ / (n+1)) + C

2. ∫ sin u du = -cos u + C

3. ∫ cos u du = sin u + C

4. ∫ sec² u du = tan u + C

5. ∫ csc² u du = -cot u + C

6. ∫ sec u tan u du = sec u + C

7. ∫ csc u cot u du = -csc u + C

8. ∫ tan u du = -ln|cos u| + C = ln|sec u| + C

9. ∫ cot u du = ln|sin u| + C

10. ∫ sec u du = ln|sec u + tan u| + C

11. ∫ csc u du = ln|csc u - cot u| + C

12. ∫ 1/√(a²-u²) du = arcsin(u/a) + C

13. ∫ 1/(a²+u²) du = (1/a) arctan(u/a) + C

14. ∫ 1/(u√(u²-a²)) du = (1/a) arcsec(|u|/a) + C

15. ∫ eᵘ du = eᵘ + C

16. ∫ aᵘ du = (aᵘ / ln a) + C

17. ∫ (1/u) du = ln|u| + C

สูตรพื้นฐานที่ **ไม่ให้** ในข้อสอบ (ต้องท่องจำเอง 100%)

กฎการดิฟพื้นฐาน

  • • d/dx(c) = 0
  • • d/dx(xⁿ) = n·xⁿ⁻¹
  • • ดิฟผลคูณ: (uv)' = u v' + v u'
  • • ดิฟผลหาร: (u/v)' = (v u' - u v') / v²
  • • กฎลูกโซ่: d/dx[f(g(x))] = f'(g(x))·g'(x)

สูตรผลต่างอนุพัทธ์ & โลปีตัล

  • • dx = Δx
  • • dy = f'(x) dx
  • • ค่าประมาณ: f(x+Δx) ≈ f(x) + f'(x)Δx
  • • รูปแบบยังไม่กำหนด: 0/0, ∞/∞
  • • กฎโลปีตัล: lim [f(x)/g(x)] = lim [f'(x)/g'(x)]

อัตราสัมพัทธ์ & พื้นที่

  • • ปริมาตรทรงกลม V = (4/3)πr³
  • • ปริมาตรกรวย V = (1/3)πr²h
  • • พื้นที่วงกลม A = πr²
  • • ปริพันธ์จำกัดเขต: ∫ₐᵇ f(x)dx = F(b) - F(a)

การหาอนุพันธ์ของฟังก์ชันพีชคณิต & ฟังก์ชันตรีโกณมิติ

ความยาก: (ง่าย - ปานกลาง)
ตรงกับคลิปในเพลย์ลิสต์: หัวข้อ 3.5 ดิฟพีชคณิต & กฎลูกโซ่ / ตรีโกณ
เปิดดูคลิป

💡 หลักการทำโจทย์แบบละเอียด & เทคนิคคิดเร็ว

เมื่อเจอโจทย์ผสม เช่น y = (4x - 3)(x² - 8x + 2) / (x - 2) หรือ f(x) = (4x³ + 9x - 1)⁷:

  1. โจทย์ฟังก์ชันประกอบ (กฎลูกโซ่): ถ้าอยู่ในรูป y = [u(x)]ⁿ ให้ตบเลขชี้กำลัง n ลงมาข้างหน้า ลบกำลังออก 1 แล้วอย่าลืมคูณด้วยดิฟไส้ใน (du/dx) เสมอ
  2. โจทย์ผลหาร: ใช้สูตร (ล่าง·ดิฟบน - บน·ดิฟล่าง) / ล่าง² กระจายพจน์บนเศษให้เรียบร้อย
  3. โจทย์ตรีโกณกำลังสูง: เช่น y = cot²(5x - 4) ให้มองเป็น y = [cot(5x - 4)]² แล้วใช้กฎลูกโซ่ 3 ชั้น (ดิฟกำลัง ➔ ดิฟ cot ➔ ดิฟมุม)

รูปแบบคำตอบที่ต้องการในข้อสอบ

ตอบในรูป dy/dx = ... หรือ f'(x) = ... โดยจัดรูปเศษส่วน จัดการกำลังติดลบให้อยู่ในรูปบวก และดึงตัวร่วมออกให้เรียบร้อย

ตัวอย่างโจทย์แสดงวิธีทำ ตัวอย่างแนวข้อสอบส่วนที่ 1

จงหา f'(x) เมื่อ f(x) = (4x³ + 9x - 1)⁷

// ขั้นที่ 1: ให้ u = 4x³ + 9x - 1 จะได้ f(x) = u⁷

f'(x) = 7(4x³ + 9x - 1)⁶ · d/dx(4x³ + 9x - 1)

// ขั้นที่ 2: ดิฟไส้ใน d/dx(4x³ + 9x - 1) = 12x² + 9

f'(x) = 7(4x³ + 9x - 1)⁶ · (12x² + 9)

ตอบ f'(x) = 21(4x² + 3)(4x³ + 9x - 1)⁶

ข้อ 2.1: y = sin(3x⁵ - 6x² + 2x)
ข้อ 2.4: y = cot²(5x - 4)sin³(x² + 1)

การหาอนุพันธ์ฟังก์ชันชี้กำลัง & ลอการิทึม (Logarithmic Diff)

ความยาก: (ปานกลาง)

💡 เทคนิค Logarithmic Differentiation (การเทก ln)

ใช้เมื่อเจอโจทย์ที่ฐานติดตัวแปร x และตัวยกกำลังก็ติดตัวแปร x เช่น y = xˣ หรือ y = (sin x)⁽ᶜᵒˢ ˣ⁾

  1. ขั้นตอนที่ 1: เทก ln ทั้งสองข้างของสมการ ➔ ln y = ln(xˣ)
  2. ขั้นตอนที่ 2: ใช้สมบัติลอการิทึมดึงกำลังมาข้างหน้า ➔ ln y = x · ln x
  3. ขั้นตอนที่ 3: หาอนุพันธ์เทียบ x ทั้งสองข้าง โดยฝั่งซ้ายได้ (1/y)(dy/dx) และฝั่งขวาใช้ดิฟผลคูณ
  4. ขั้นตอนที่ 4: ย้าย y กลับขึ้นไปคูณฝั่งขวา แล้วแทนค่า y = xˣ กลับเข้าไป

ตัวอย่าง: กำหนดให้ y = xˣ จงหา dy/dx

1. ln y = ln(xˣ) ➔ ln y = x ln x

2. d/dx(ln y) = d/dx(x ln x)

3. (1/y) dy/dx = x(1/x) + (ln x)(1) = 1 + ln x

4. dy/dx = y(1 + ln x)

ตอบ dy/dx = xˣ(1 + ln x)

ฟังก์ชันโดยปริยาย (Implicit) & อนุพันธ์อันดับสูง

ความยาก: (ปานกลาง)

💡 กฎเหล็กฟังก์ชันโดยปริยาย (Implicit Diff)

เมื่อสมการปน x และ y เช่น x² + xy + y² - 1 = 0:

  • ดิฟพจน์ x ตามปกติ
  • ดิฟพจน์ y แล้วต้องคูณติด (dy/dx) เสมอ เช่น d/dx(y²) = 2y(dy/dx)
  • พจน์คูณกัน xy ต้องใช้ดิฟผลคูณ: x(dy/dx) + y(1)
  • ย้ายพจน์ที่มี dy/dx ไว้ฝั่งซ้าย ดึงตัวร่วม แล้วย้ายตัวคูณไปหาร

ข้อ 3: x²y + e⁽ˣ⁺ʸ⁾ + tan y = 1 ที่จุด (0,0)
ข้อ 4(3): y = e²ˣ cos x จงหา y⁽⁴⁾

ผลต่างอนุพัทธ์ (Differentials dy, dx) & การประมาณค่า

ความยาก: (ปานกลาง)

💡 สัญลักษณ์สำคัญ & สูตรประมาณค่า

  • dx = Δx (การเปลี่ยนแปลงของ x)
  • dy = f'(x) dx (ผลต่างอนุพัทธ์ของ y)
  • สูตรประมาณค่า: f(x + Δx) ≈ f(x) + dy = f(x) + f'(x)Δx

ตัวอย่าง: ใช้ผลต่างอนุพัทธ์หาค่าประมาณ √98

1. กำหนด f(x) = √x, เลือก x = 100 (คิดง่าย), Δx = -2 (เพราะ 100 - 2 = 98)

2. f(100) = √100 = 10

3. f'(x) = 1/(2√x) ➔ f'(100) = 1/(2·10) = 0.05

4. dy = f'(100)·Δx = (0.05)(-2) = -0.10

ตอบ √98 ≈ 10 + (-0.10) = 9.90

การวิเคราะห์ลักษณะกราฟ & ปัญหาค่าสุดขีด (Optimization)

ความยาก: (ยาก)

💡 สรุปเงื่อนไขกราฟ & จุดวิกฤต

  • จุดวิกฤต (Critical Point): แก้สมการหาค่า x จาก f'(x) = 0 หรือหาค่าไม่ได้
  • ฟังก์ชันเพิ่ม/ลด: ดูเครื่องหมายของ f'(x) (+ คือ เพิ่ม, - คือ ลด)
  • ความเว้าบน/เว้าล่าง: ดูเครื่องหมายของ f''(x) (+ คือ เว้าบน, - คือ เว้าล่าง)

กฎของโลปีตัล (L'Hospital's Rule)

ความยาก: (ปานกลาง)

💡 ลำดับการใช้กฎของโลปีตัล

  1. ต้องเช็ค Indeterminate Form (I.F.) ก่อนเสมอ: เช่น [0/0] หรือ [∞/∞] (ถ้าไม่เช็คระวังโดนหักคะแนน)
  2. ใช้กฎโลปีตัล ดิฟเศษแยก ดิฟส่วนแยก ➔ lim [f'(x) / g'(x)]
  3. รูปแบบ 0 · ∞ ให้จัดรูปเป็นเศษส่วนก่อน เช่น lim (x² ln x) = lim (ln x / (1/x²)) แล้วคูณดิฟโลปีตัล

การหาปริพันธ์ไม่จำกัดเขต & จำกัดเขต (u-Substitution)

ความยาก: (ปานกลาง - ยาก)

💡 เทคนิคเปลี่ยนตัวแปร u (u-Substitution)

  1. เลือกตัวแปร u จากพจน์ที่ซับซ้อน หรือพจน์ใต้ก้อนยกกำลัง เช่น u = x³ - 1
  2. หา du = u'(x) dx ➔ dx = du / u'(x)
  3. แทนค่าเปลี่ยนรูปอินทิเกรตให้อยู่ในรูปตัวแปร u ทั้งหมด แล้วทำการอินทิเกรต
  4. อย่าลืม: ปริพันธ์ไม่จำกัดเขตต้อง + C เสมอ! ส่วนปริพันธ์จำกัดเขตให้นำขอบเขตไปแทนค่า F(b) - F(a)

ข้อที่อยากให้ฝึกทำในใบงานที่ 13

ข้อ 1: ∫₀¹ (x³ - 1)¹⁰ x² dx
ข้อ 2: ∫ (4x³ + 1) sin(x⁴ + x) dx
ข้อ 6: ∫₋₂² |x + 1| dx
